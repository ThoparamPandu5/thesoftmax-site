# The Softmax — daily AI news for students

Live site: https://ai.thesoftmax.workers.dev

- `index.html` — website design (UI)
- `updates.js` — the news list (add new items at the top)
- `wrangler.jsonc` — Cloudflare settings
- `.assetsignore` — files Cloudflare should not publish

Any change committed to `main` is deployed automatically by Cloudflare.
